# VideoEnhancer

[English](../../README.md) · Español

VideoEnhancer es una aplicación para Windows en desarrollo. Su objetivo es restaurar vídeos dañados por la compresión y suavizar el movimiento, conservando el aspecto original de las personas, el maquillaje y los colores.

La primera versión de desarrollo permite ampliar vídeos, crear fotogramas intermedios mediante mezcla, guardar el progreso, reanudar tareas interrumpidas y trabajar en los horarios elegidos. La restauración con IA y la interfaz gráfica están previstas para versiones posteriores.

Requiere una GPU NVIDIA RTX. Los vídeos permanecen en tu ordenador.

Consulta la [guía de desarrollo](../DEVELOPMENT.md) para la configuración y los comandos. El código tiene licencia [MIT](../../LICENSE); los modelos opcionales tienen sus propias licencias.
