# VideoEnhancer

[English](../../README.md) · Português

VideoEnhancer é um aplicativo para Windows em desenvolvimento. Seu objetivo é restaurar vídeos danificados pela compressão e tornar os movimentos mais suaves, preservando a aparência original das pessoas, a maquiagem e as cores.

A primeira versão de desenvolvimento permite ampliar vídeos, criar quadros intermediários por mistura, salvar o progresso, retomar tarefas interrompidas e trabalhar nos horários escolhidos. A restauração com IA e a interface gráfica estão previstas para versões futuras.

Requer uma GPU NVIDIA RTX. Os vídeos permanecem no seu computador.

Consulte o [guia de desenvolvimento](../DEVELOPMENT.md) para configuração e comandos. O código usa a licença [MIT](../../LICENSE); os modelos opcionais têm licenças próprias.
