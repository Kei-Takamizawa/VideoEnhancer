# VideoEnhancer

[English](../../README.md) · 한국어

VideoEnhancer는 개발 중인 Windows 앱입니다. 압축으로 손상된 영상을 복원하고 움직임을 부드럽게 하면서 사람의 원래 모습, 메이크업, 색감을 유지하는 것을 목표로 합니다.

첫 개발 버전에서는 영상 확대, 인접 프레임 혼합을 통한 중간 프레임 생성, 진행 상태 저장, 중단된 작업 재개, 지정 시간대 처리가 가능합니다. AI 화질 복원과 그래픽 인터페이스는 이후 버전에 계획되어 있습니다.

NVIDIA RTX GPU가 필요합니다. 영상은 사용자의 컴퓨터에 보관됩니다.

설정 및 명령은 [개발 가이드](../DEVELOPMENT.md)를 참고하세요. 코드는 [MIT 라이선스](../../LICENSE)이며 선택적 AI 모델에는 별도 라이선스가 적용됩니다.
