# VideoEnhancer

[English](../../README.md) · Français

VideoEnhancer est une application Windows en développement. Elle vise à restaurer les vidéos abîmées par la compression et à rendre les mouvements plus fluides, tout en préservant l'apparence des personnes, leur maquillage et les couleurs.

La première version de développement permet d'agrandir les vidéos, de créer des images intermédiaires par mélange, de sauvegarder la progression, de reprendre les tâches interrompues et de travailler aux horaires choisis. La restauration par IA et l'interface graphique sont prévues pour des versions ultérieures.

Une carte NVIDIA RTX est nécessaire. Vos vidéos restent sur votre ordinateur.
