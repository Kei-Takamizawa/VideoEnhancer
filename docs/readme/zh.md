# VideoEnhancer

[English](../../README.md) · 中文

VideoEnhancer是一款正在开发的Windows应用。它旨在修复压缩造成的视频损伤，使动作更流畅，同时保留人物外观、妆容和色彩。

首个开发版本支持视频放大、通过混合相邻帧生成中间帧、保存进度、恢复中断的任务，以及按指定时间段处理。AI画质修复和图形界面将在后续版本中提供。

需要NVIDIA RTX GPU。视频始终在您的电脑上处理。

开发设置及命令请参阅[开发指南](../DEVELOPMENT.md)。代码采用[MIT许可证](../../LICENSE)，可选AI模型采用各自的许可证。
