# VideoEnhancer

[English](../../README.md) · 日本語

VideoEnhancerは開発中のWindows向けアプリです。圧縮で傷んだ動画の画質を改善し、人の見た目、メイク、色合いを保ちながら動きを滑らかにすることを目指しています。

最初の開発版では、動画の拡大、隣接フレームの混合による中間フレームの作成、進捗保存、中断した処理の再開、指定した時間帯での処理ができます。AIによる画質復元とグラフィカルな操作画面は今後実装予定です。

NVIDIA RTX GPUが必要です。動画はお使いのパソコン内で処理します。

開発用の設定とコマンドは[開発ガイド](../DEVELOPMENT.md)をご覧ください。コードは[MITライセンス](../../LICENSE)です。任意のAIモデルには別のライセンスがあります。
