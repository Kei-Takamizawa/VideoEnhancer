# VideoEnhancer

[English](../../README.md) · Русский

VideoEnhancer — разрабатываемое приложение для Windows. Оно предназначено для восстановления видео, повреждённого сжатием, и повышения плавности движения с сохранением внешности людей, макияжа и цветов.

Первая версия для разработки позволяет увеличивать видео, создавать промежуточные кадры смешиванием соседних, сохранять прогресс, возобновлять прерванные задачи и работать в выбранные часы. Восстановление качества с помощью ИИ и графический интерфейс запланированы на следующие версии.

Требуется видеокарта NVIDIA RTX. Видео остаются на вашем компьютере.

Настройка и команды описаны в [руководстве разработчика](../DEVELOPMENT.md). Код распространяется по лицензии [MIT](../../LICENSE); дополнительные модели ИИ имеют отдельные лицензии.
