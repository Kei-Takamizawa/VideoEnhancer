# VideoEnhancer

[English](../../README.md) · العربية

VideoEnhancer تطبيق لنظام Windows قيد التطوير. يهدف إلى إصلاح الفيديو المتضرر من الضغط وجعل الحركة أكثر سلاسة، مع الحفاظ على المظهر الأصلي للأشخاص والمكياج والألوان.

تتيح النسخة التطويرية الأولى تكبير الفيديو، وإنشاء إطارات وسيطة بمزج الإطارات المتجاورة، وحفظ التقدم، واستئناف المهام المتوقفة، والعمل ضمن الأوقات التي تختارها. استعادة الجودة بالذكاء الاصطناعي والواجهة الرسومية مخطط لهما في إصدارات لاحقة.

يتطلب بطاقة NVIDIA RTX. تبقى مقاطع الفيديو على جهازك.

لإعداد بيئة التطوير والأوامر، راجع [دليل التطوير](../DEVELOPMENT.md). الكود مرخص بموجب [MIT](../../LICENSE)، ولنماذج الذكاء الاصطناعي الاختيارية تراخيص منفصلة.
